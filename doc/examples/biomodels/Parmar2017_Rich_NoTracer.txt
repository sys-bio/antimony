# Mouse Iron Distribution Dynamics

Dynamic model of iron distribution in mice. This model includes only normal iron
with the parameters that fit the data from Lopes *et al.* 2010 for mice fed a rich
iron diet.

This model does not include the radioiron tracer species. It is appropriate to study
the properties in conditions where no tracers are used (for example for steady state
analysis).
